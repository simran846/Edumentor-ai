# EduMentor AI — Your Personal AI Mentor for Learning & Career Growth

EduMentor AI is a modern, responsive EdTech web platform designed to accelerate student learning and tech career placement through personalized 12-week roadmaps, adaptive smart quizzes, skill gap analysis, and ATS resume engineering.

![EduMentor AI Banner](https://images.unsplash.com/photo-1516321318423-f06f85e504b3?w=1200&auto=format&fit=crop&q=80)

---

## ✨ Features

- **24/7 AI Personal Mentor:** Conversational AI mentor that generates adaptive 12-week roadmaps based on dream target roles and background knowledge.
- **Personalized Learning Paths:** 8 curated tracks spanning Backend, Full Stack, AI & ML, Data Science, Cloud & DevOps, Cybersecurity, and Competitive Programming.
- **Adaptive Smart Quizzes:** Real-time knowledge evaluations with immediate visual feedback, countdown timers, confetti celebrations, and AI concept explanations.
- **Student Command Center (Dashboard):** Track weekly consistency heatmaps, 14-day streaks, hours learned, quiz accuracy, and upcoming milestones.
- **Career & Skill Gap Hub:** Algorithmic skill gap calculator that compares profile readiness against real tech job requirements (e.g., Razorpay, Swiggy, Zerodha).
- **ATS Resume Engineering Studio:** Interactive resume builder with real-time ATS scoring (86/100 → 94/100), AI bullet polish, and instant Print/PDF export.
- **Pricing & Institution:** Transparent tiered pricing (Free, Pro ₹299/mo, Institution) with comparison matrix.
- **Aesthetic UI:** Designed with Tailwind CSS, Lucide icons, glassmorphism, smooth micro-animations, and full dark mode support.

## 🛠️ Tech Stack

- **Framework:** React 18 with TypeScript
- **Bundler:** Vite
- **Styling:** Tailwind CSS + Custom Design System
- **Icons:** Lucide React
- **Celebrations:** Canvas Confetti

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/simran846/edumentor-ai.git
cd edumentor-ai
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

The application will be live at `http://localhost:3000/`.

### 4. Build for production
```bash
npm run build
```
